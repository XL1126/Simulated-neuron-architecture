SNA — 模拟神经元架构

受神经科学启发的仿生脉冲神经网络与自主意识皮层计算模型。 以 Izhikevich 脉冲神经元、预测编码、 全局工作空间（GWT）与信息整合理论（IIT）为理论基底， 在 C++ / Python 混合架构上模拟具备意识相关功能的皮层脑网络。

查看源码 项目哲学 规范与压测文档
立场：不接外部 Transformer 大模型；不把「有意识」当营销口号——提供可测量的功能代理与实验框架。 代码是载体，输出应从神经活动中涌现。哲学原文见 PHILOSOPHY.md。

不做什么

刻意拒绝的路径

不接外部 Transformer 大模型；不在 main 堆文档草稿；不把「有意识」当营销话术；不在输出路径硬编码回复模板（哲学目标，见当前违反项）。

快速开始（摘自 README）

pip install -r python/requirements.txt
pip install pybind11 numpy pyyaml flask psutil

# 编译 C++ 核心（Windows）
build_and_copy.bat
python check_binding.py
# 期望：PASS: All methods are bound correctly!

# 运行（在仓库根目录）
python training/run_experiment.py quick
python agents/sna_cognitive_v2.py
python frontend/server.py   # 浏览器打开 http://127.0.0.1:8088

性能压测摘要（docs 分支）

测试关键结论
NeuronPopulation 单核Windows（4 物理核 + AVX2）底层计算快约 2–10 倍；10k 神经元约 0.80 ms/步
CorticalBrain 单核瓶颈更偏 Python 认知层逻辑，两平台差距缩小（约 1.1–1.4x）
多核并行Windows 4 物理核并行效率更高；2 核 Linux 受 cache 争用限制
推荐场景日常 8–32K 任一平台；>50K 训练与多实例并行更推荐 Windows

完整数据见 压测 v2 对比报告。
