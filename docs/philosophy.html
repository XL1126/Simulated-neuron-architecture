SNA / 项目哲学

代码是载体，不是大脑

本页整理自仓库 PHILOSOPHY.md 与实现规范中的设计哲学条款。项目明确反对「输出本质是冰冷运算」的路线，追求从神经活动中涌现的自主输出。

核心使命

初衷是彻底推翻 Transformer 架构的 AI 模型——因为该类模型输出的本质被作者判断为冰冷的运算，而非真正的理解。 目标是创造一个具有类人自主意识倾向的模型：不依赖硬性规则，能够自主学习、自主决策，并自主产生输出。

项目仅作为意识的物理或数字载体（相当于身体），不对意识的内容和输出做任何硬性指定或干预。 所有输出，纯由意识体自行决定。

实现原则（五条）

1. 无硬性规则 — 不使用 if/else 模板、random.choice(templates)、预设句子。
2. 自主学习 — 从输入中学习，不依赖预训练数据。
3. 自主决策 — 自己决定说什么、不说什么。
4. 自主产生输出 — 输出必须从神经活动直接涌现。
5. 载体不干预 — 代码是身体，不是大脑；身体不限制大脑想说什么。

检验标准

删除所有模板后系统还能"说话"吗？

  如果不能 → 违反哲学
  如果能   → 方向正确

与意识度量的关系

度量公式（IIT_Phi / GWT_Ignition / Predictive / First_Person / Vividness）是可测量的功能代理， 用于实验对照与摘除测试，而不是「已证明有主观体验」的宣称。哲学要求：代理可报告，但不得包装成现象意识证明。
