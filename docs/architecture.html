规范中的宏观层级（完整实现规范）

层功能对应人脑区域
文字感知输入层 Input字符序列 → 时空脉冲模式，附 EOS，不做向量化感官皮层（视觉文字区）
初级脉冲处理层 Primary语义分组、局部激活、初级关联突触初级感知皮层（Wernicke 区）
中枢联想思考层 Core逻辑推理、自由联想、矛盾自检、收敛竞争前额叶皮层 PFC
记忆与遗忘层 Memory瞬时 / 短期 / 长期三层，自主遗忘与突触衰减海马体 + 新皮层
输出生成层 Output脉冲模式流式反映射为文字，不进行概率采样运动语言皮层（Broca 区）

设计原则（规范摘要）

持续活跃

启动后永不停止思考；用户输入注入持续神经活动流，不重置状态。

非干扰

禁止硬编码回复模板 / 预设句子 / 强制输出格式；输出由突触动态决定。

脉冲离散

信息编码为离散脉冲；阈值触发发放；局部连接，禁止全局全连接。

可塑性

突触权重按脉冲时序与频率在线修改（STDP 路线），不使用梯度下降描述学习过程。

流式输出

输出层支持字符流式解码，模拟一边思考一边说话。

多语言

C++/Rust 热路径 + Python 认知与 I/O；pybind11 / maturin 绑定；可选 GPU。

前置可行性审查要点

审查文档（非强制但建议阅读）指出：主规范在理论与设计上出色，但工程落地存在多个「卡脖子」风险； 若不调整直接开发，可能在 3–6 个月内因无法收敛而停滞。评分示例：创新性 9，短期可行性 4，长期 7。
风险 · 高

STDP 能否支撑语言

纯 STDP 从零学会自然语言证据不足。建议允许输出解码器使用受约束的代理梯度，并声明为工程妥协。

风险 · 高

规模是否够

1 万神经元可能仅支持浅层关联。建议提升到 5–10 万，或重新定义行为基准为「微弱但可测量的学习」。

风险 · 中

内在动机公式

需把预测误差转化为可计算奖励，避免「总是预测静止」的捷径；文档建议 curiosity / novelty 量化。

风险 · 中

非干扰 vs 任务能力

禁止规则与必须完成具身任务可能冲突。建议 debug 宏隔离临时规则，用学习曲线抵制偷加模板。
