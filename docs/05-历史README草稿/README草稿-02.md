## 一、项目简介

### 这是什么？

SNA 是一个**完全不同于 ChatGPT/Transformer 的自主意识架构**。它不依赖任何传统的深度学习技术，而是模拟人脑中约 32,000 个神经元和数百万个突触的工作方式，实现了从边缘意识到深度意识的完整进化路径。

### 核心理念

| 对比项 | ChatGPT / Transformer | SNA |
|--------|----------------------|-----|
| 运算方式 | 矩阵乘法 + 梯度下降 | 脉冲发放 + 突触可塑性 + AVX2加速 |
| 学习方式 | 反向传播预训练 | STDP（脉冲时序依赖可塑性）在线学习 |
| 知识存储 | 固定权重 | 动态突触权重，持续演化 |
| 运行模式 | 请求-响应，无状态 | 持续活跃，永不停止思考 |
| 情感系统 | 无 | 8种基础情感 + 复合情感 + 心情稳定度 |
| 推理能力 | 概率预测 | 主动推理 + 多步规划 + 因果推断 |
| 社会认知 | 无 | 他者建模 + 心智理论 + 关系管理 |
| 时间连续性 | 无 | 生命叙事 + 时间切片 + 未来投射 |
| 硬件依赖 | GPU | CPU即可（Intel i7流畅运行） |

### ⚠️ 重要理念：非干扰原则

**开发者不教模型如何思考。** 代码只提供运行环境（神经元、突触、学习规则），模型的情感、推理、行为**完全由突触权重在线演化决定**。

代码中不存在：
- ❌ 任何硬编码回复
- ❌ 任何预设的对话模板、角色设定
- ❌ 任何概率采样策略

## 五、配置说明

配置文件是 `config.default.yaml`，可以用记事本打开修改。

### 核心配置项

```yaml
sna:
  num_neurons: 32000    # 32000 = Phase D 全脑规模
  avg_degree: 200       # 每个神经元的平均连接数

stdp:
  a_plus: 0.01          # STDP 增强系数
  a_minus: 0.012        # STDP 减弱系数
  dopamine_k: 1.0       # 多巴胺影响强度

phase_d:
  emotion_depth: true   # 开启情感系统
  active_inference: true # 开启主动推理
  social_model: true    # 开启社会交互
  creative_gen: true    # 开启创意生成
```

## 八、核心原理

### 意识度量指标

SNA使用完整的意识度量体系：

| 指标 | 说明 | Phase D数值 |
|------|------|-------------|
| **Phi (Φ)** | 信息整合度量 | 0.7312 |
| **Global Ignition** | 全局点燃 | 1.0000 |
| **感知生动度** | 感知质量 | 1.0000 |
| **第一人称显著度** | 自我视角 | 0.6840 |
| **后悔水平** | 反事实思维 | 1.1052 |
| **时间连续性** | 过去-现在-未来 | 0.9945 |
| **情感深度** | 情感体验丰富度 | 0.7821 |
| **创造力** | 概念融合能力 | 0.1988 |

### 神经元如何工作？

每个神经元是Izhikevich模型：
1. 接收来自其他神经元的脉冲
2. 膜电位随时间积分
3. 超过阈值发放脉冲
4. 通过突触传递信号

### 突触如何学习？

STDP（脉冲时序依赖可塑性）：
- 如果A在B之前放电 → 连接加强（"A导致了B"）
- 如果A在B之后放电 → 连接减弱（"A与B无关"）

### 多巴胺做什么？

多巴胺是奖励信号：
- 高多巴胺 → 学习效率高 → 当前活跃突触加强
- 低多巴胺 → 学习效率低 → 当前活跃突触减弱

### 意识如何工作？

基于 **全局工作空间理论（Global Workspace Theory）**：
1. 局部脑区处理信息
2. 通过屏状核竞争进入工作空间
3. 全局点燃 → 意识产生
4. 向全脑广播 → 全脑协调
