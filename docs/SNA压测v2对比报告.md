# SNA 极限压测 v2 对比报告

> 生成时间: 2026-05-10 23:10

## 测试环境

| 项目 | Kali Linux | Windows |
|------|-----------|---------|
| 系统 | Linux x86_64 | Windows Intel64 |
| CPU | 2 物理核 / 4 逻辑核 | 4 物理核 / 8 逻辑核 |
| Python | 3.13.7 | 3.11.0 |
| 编译器 | GCC 14.3.0 (-O3 -march=native) | MSVC (/O2 /arch:AVX2) |

## Test 1: NeuronPopulation 单核 (底层计算热路径)

| 神经元 | Kali ms/步 | Win ms/步 | Win 快几倍 |
|--------|-----------|----------|-----------|
| 10,000 | 7.94 | 0.80 | **9.9x** |
| 50,000 | 13.53 | 6.82 | **2.0x** |
| 100,000 | 27.24 | 14.28 | **1.9x** |
| 200,000 | 84.30 | 28.00 | **3.0x** |
| 500,000 | 182.75 | 68.39 | **2.7x** |
| 1,000,000 | 335.27 | 139.66 | **2.4x** |

**结论: Windows 底层计算快 2-10 倍**，得益于 4 物理核 + AVX2 向量化。

## Test 2: CorticalBrain 单核 (完整模拟)

| 神经元 | Kali ms/步 | Win ms/步 | Win 快几倍 |
|--------|-----------|----------|-----------|
| 8,000 | ~3-55* | 2.78 | ~1-20x |
| 16,000 | 6.59 | 5.92 | **1.1x** |
| 24,000 | 11.41 | 9.94 | **1.1x** |
| 32,000 | 18.19 | 15.10 | **1.2x** |
| 48,000 | 33.50 | 30.00 | **1.1x** |
| 64,000 | 435.81* | 304.44 | **1.4x** |

*CorticalBrain 的差距比 NeuronPopulation 小得多*，因为 CorticalBrain 包含大量 Python 层逻辑（全局工作空间、意识计算、语言层等），这些不受益于硬件优化。

## Test 3: 多核并行 — NeuronPopulation (100K 神经元/进程)

| 进程 | Kali 总吞吐 | Kali 效率 | Win 总吞吐 | Win 效率 |
|------|-----------|----------|-----------|----------|
| 1 | 356.2 | 100% | 71.1 | 100% |
| 2 | 57.5 | 8.1% | 82.5 | 58% |
| 3 | 59.2 | 5.5% | 84.0 | 39% |
| 4 | 53.1 | 3.7% | 80.7 | 28% |

**Kali 并行效率极差** (3.7%) — 2 物理核跑 4 进程，cache 争用严重。
**Windows 并行更好** (28-58%) — 4 物理核能真正并行。

## Test 4: 多核并行 — CorticalBrain (16K 神经元/进程)

| 进程 | Kali 总吞吐 | Kali 效率 | Win 总吞吐 | Win 效率 |
|------|-----------|----------|-----------|----------|
| 1 | 147.3 | 100% | 163.0 | 100% |
| 2 | — | — | 221.5 | 68% |
| 3 | 141.4 | 32% | 249.5 | 51% |
| 4 | 146.5 | 25% | 247.0 | 38% |

**单核吞吐几乎一样** (~150-163 步/秒)，说明 CorticalBrain 的瓶颈在 Python 层而非 C++ 计算。
**Windows 多核加速 1.5x**，Kali 基本无加速。

## 关键发现

### 1. 硬件差距
- Windows: **4 物理核 / 8 逻辑核 + AVX2** → 底层计算快 2-10x
- Kali: **2 物理核 / 4 逻辑核** → 并行时 cache 争用严重

### 2. 瓶颈转移
- **小规模 (<32K)**: CorticalBrain 瓶颈在 Python 层逻辑，两台机器差距小
- **大规模 (>50K)**: C++ 计算占比增大，Windows 优势明显
- **并行**: Kali 受限于物理核数，Windows 有真正扩展空间

### 3. Kali 8K 异常
8000 神经元在 Kali 上有时 3ms 有时 55ms，可能是 CPU 调频预热问题。建议:
```bash
echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
```

## 建议

| 场景 | 推荐平台 | 原因 |
|------|---------|------|
| 日常开发 (8-32K) | 任一 | 差距不大 |
| 大规模训练 (>50K) | **Windows** | 底层计算快 2-3x |
| 多实例并行训练 | **Windows** | 4 物理核并行效率高 |
| 极限规模 (>1M) | **Windows** | 内存和计算都更充裕 |
