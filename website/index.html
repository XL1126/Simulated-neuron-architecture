SNA — 模拟神经元架构

仿生脉冲神经网络与自主意识皮层计算模型。 基于 Izhikevich 神经元、预测编码、全局工作空间（GWT）与信息整合理论（IIT）， 在 C++ / Python 混合架构上模拟意识相关功能皮层脑网络。

查看源码 同作者 NOUS 项目
立场： 不接外部 Transformer 大模型；不把「有意识」当营销口号——提供可测量的功能代理与实验框架。 代码是载体，输出应从神经活动中涌现。

项目定位

脉冲皮层

C++ CorticalBrain 承载 V1/V2、运动、海马、前额叶、杏仁核、丘脑、屏状核、DMN 等区域模块。

认知层

Python 层负责统一意识度量、Phi 校验、SPA 语义指针、工作记忆与世界模型。

实验体系

training/ 与 experiments/ 提供实验入口与配方；tests/ 含单元与摘除测试。

前端交互

frontend/ 提供聊天前端 + Flask API（端口 8088），可对接本地守护进程。

仓库分支

main

主线源码：C++ 引擎、Python 认知层、agents、training、前端、运行时备份。

docs

文档专库：实现规范、可行性审查、压测报告、部署参考（无业务代码）。

legacy-v1

历史 V1.0 快照，不再维护，仅供对照。

技术栈

Python

≥ 3.8 · 认知层 / agents / training / 前端 API

C++

MSVC 2019+ 或 GCC 9+ · 脉冲皮层核心引擎

CMake

≥ 3.18 · 编译构建（Windows 可用 build_and_copy.bat）

pybind11

C++ ↔ Python 绑定（core_cpp），绑定检查：check_binding.py

生态

numpy · pyyaml · flask · pytest · 可选 psutil
